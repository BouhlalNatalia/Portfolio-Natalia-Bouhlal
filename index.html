Projekte

ICHGram

GitHub Live-Demo

Soziales Netzwerk zum Teilen von Fotos, entwickelt als Full-Stack-Anwendung mit React, TypeScript und Node.js. Nutzer legen ein Profil an, posten Fotos, liken, kommentieren, folgen anderen und chatten in Echtzeit.

React TypeScript Redux Toolkit Node.js Express MongoDB Mongoose Socket.IO JWT Cloudinary Multer Nodemailer
  • Anmeldung: Registrierung, Login und JWT-Authentifizierung. Passwörter werden mit bcrypt gehasht.
  • Soziale Funktionen: Profile, Foto-Beiträge, Likes, Kommentare, Follower und Benachrichtigungen.
  • Echtzeit-Chat: Nachrichten und Chat-Updates in Echtzeit mit Socket.IO.
  • Bilderspeicher: Beitragsfotos und Profilbilder liegen in Cloudinary.
  • Deployment: Die App läuft auf Render, die Daten liegen in MongoDB Atlas.
