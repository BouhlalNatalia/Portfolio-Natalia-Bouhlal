SCHRIFT NUNITO LOKAL EINBINDEN
==============================
Die Seite nutzt die Schrift "Nunito" (Lizenz: SIL Open Font License, frei nutzbar).
Damit beim Besuch KEINE Verbindung zu Google aufgebaut wird, müssen zwei Dateien
in DIESEM Ordner (fonts/) liegen:

  nunito-latin-wght-normal.woff2       (deutsch / englisch)
  nunito-cyrillic-wght-normal.woff2    (russisch)

Download (Fontsource, variable Schrift, alle Stärken in einer Datei):
  https://cdn.jsdelivr.net/npm/@fontsource-variable/nunito/files/nunito-latin-wght-normal.woff2
  https://cdn.jsdelivr.net/npm/@fontsource-variable/nunito/files/nunito-cyrillic-wght-normal.woff2

Die Links einfach im Browser öffnen -> Datei speichern -> hier ablegen.
(Falls ein Link nicht mehr geht: https://fontsource.org/fonts/nunito -> "Download".)

Solange die Dateien fehlen, funktioniert die Seite trotzdem; es wird dann
eine Standard-Schrift des Geräts angezeigt.
